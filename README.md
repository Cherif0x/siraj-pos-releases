# 📱 سراج - نظام إدارة المخزون ونقاط البيع

![Sirage Logo](./Resources/Images/logo.png)

## 🇲🇷 مرحباً بك في سراج

**سراج** هو برنامج سهل وعملي لإدارة محلك التجاري، مصمم خصيصاً للسوق الموريتاني.

### ⭐ لماذا سراج؟

✅ **سهل الاستخدام** - واجهة بسيطة باللغة العربية والفرنسية  
✅ **يعمل بدون إنترنت** - لا تحتاج اتصال بالإنترنت  
✅ **إدارة المخزون** - تتبع منتجاتك وكمياتها  
✅ **نقطة بيع سريعة** - بيع وطباعة الفواتير بسهولة  
✅ **تقارير واضحة** - اعرف أرباحك ومبيعاتك  
✅ **إدارة الديون** - تتبع ديون العملاء والموردين  
✅ **طباعة حرارية** - دعم طابعات الفواتير  

---

## 🚀 البدء السريع

### تسجيل الدخول الأول
```
اسم المستخدم: admin
كلمة المرور: admin
```

> ⚠️ **مهم:** غيّر كلمة المرور فوراً من الإعدادات!

### خطواتك الأولى
1. غيّر كلمة المرور
2. أدخل بيانات محلك
3. أضف بعض المنتجات
4. جرّب عملية بيع

---

## 📋 الميزات الأساسية

### 🛒 البيع
- بيع سريع بالباركود أو البحث
- طرق دفع متعددة (نقدي، آجل، جزئي)
- طباعة الفواتير مباشرة

### 📦 المخزون
- إضافة وتعديل المنتجات
- تنبيهات عند نقص المخزون
- تصنيف المنتجات

### 💰 المالية
- تقارير المبيعات اليومية
- حساب الأرباح
- تتبع المصروفات

### 👥 العملاء والموردين
- إدارة بيانات العملاء
- تتبع الديون
- سجل المشتريات
